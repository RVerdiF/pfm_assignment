Scope delivered (all criteria map to code under streamlit/ + tests + docs)
--------------------------------------------------------------------------
* streamlit/warehouse_bootstrap.py  - centralized bootstrap decision:
    - PROJECT_ROOT-relative paths; resolves PFM_DUCKDB_PATH override.
    - warehouse_needs_build()/required_marts_present(): rebuild only when the
      file is missing OR the required marts (marts.fct_revenue_attribution,
      marts.fct_commission_daily_local, marts.mart_attribution_health) are
      absent.
    - run_ingestion() -> `python ingestion/load_excel.py`; run_dbt_build() ->
      `dbt build` (project-local profiles.yml created from example when absent;
      DBT_PROFILES_DIR pinned to the project; no ~/.dbt touched).
    - get_warehouse_connection() @st.cache_resource: opens DuckDB read-only
      ONLY after the pipeline succeeds; once per session; raises PipelineError
      with readable output on failure.
    - connection_for_app(): renders st.error + code block + actionable info;
      pages st.stop() on failure.
    - read_relation(): marts-only helper; no raw/staging/intermediate access.
* streamlit/app.py  - entrypoint wiring navigation via st.Page/st.navigation.
* streamlit/sections/  - overview.py (problem + pipeline + mart counts +
